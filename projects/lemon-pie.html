LemonPie

A compact command-line client for Ollama, built to be tiny and portable — ideal for lightweight systems and terminal users, but usable anywhere with Python and network access. LemonPie manages chat sessions and persists history locally, without getting in the way.

Key Features

  • Session Management: Start, list, resume, title, and close chat sessions, with history persisted in your OS's standard user data directory.
  • Model Aliases: Add, remove, and list Ollama models under short aliases via lmConfig, then switch models mid-session with confirmation.
  • Real-Time Streaming: Responses stream from Ollama as they're generated, with graceful handling of Ctrl-C interrupts.
  • Safe by Default: Config and session writes are atomic (tmp + replace), and both directories are overridable via environment variables for testing or containerized use.
